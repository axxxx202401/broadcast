# IM Monitor 使用手册

面向普通用户的完整使用指南。

## 1. 初次启动

首次打开应用时，会直接进入登录页。若此前已登录过，会尝试自动恢复上次会话；若恢复失败，会提示重新登录。

## 2. 登录与认证

### 2.1 基本登录

1. 在登录页选择登录方式（手机验证码 / 邮箱验证码 / 手机密码 / 邮箱密码）
2. 填写手机号或邮箱
3. 点击「发送验证码」，等待短信/邮件
4. 输入收到的验证码
5. 完成页面内 Geetest 图形验证（拖动滑块或点击识别图）
6. 点击「登录」

### 2.2 二次校验

部分账号可能在登录时触发二次校验，例如：

- 需要补充密码
- 需要人脸验证
- 需要交易密码或 Google 验证码

此时页面会动态展示对应输入项，按提示补充后即可继续。

### 2.3 登录错误处理

- 「验证码错误」：重新发送验证码后重试
- 「图形验证超时」：刷新页面重新挑战
- 「账号被限制」：联系对应平台客服

## 3. 主界面概览

登录成功后进入主界面，分为三块：

- **顶部栏**：显示当前账号、连接状态、连接/断开按钮、主题切换
- **左侧群列表**：显示已关注群组，支持搜索与监控开关
- **右侧消息区**：显示选中群（或全部）的消息，顶部含开奖信息条

### 3.1 连接状态

顶栏状态徽章有三种状态：

- **断开（灰色）**：未建立 TCP 连接，不会收到实时消息
- **连接中（黄色）**：正在建立连接，稍等片刻
- **已连接（绿色）**：实时监控已启用，新消息会实时出现

手动点击「连接聊天」可建立连接；点击「断开」可主动断开。断连不影响本地已保存的历史消息。

## 4. 群组与监控

### 4.1 查看群组

左侧列表展示所有已关注群组，每条包含：

- 群头像与群名称
- 成员数
- 监控开关（灰色=未监控，高亮=已监控）
- 最近更新标识

### 4.2 搜索群组

顶栏搜索框可按群名称或群 ID 过滤列表。清空搜索框即恢复全量。

### 4.3 开启/关闭监控

点击某群的开关即可：

- 开启：建立该群的 TCP 接收链路，消息开始写入本地数据库
- 关闭：断开该群的接收链路，但历史消息仍保留

「全部群消息」视图只显示**已开启监控**的群的消息。

### 4.4 刷新群列表

点击「刷新」按钮从服务端同步最新群组状态。被删除的群会从本地列表移除，监控设置也会重新对齐。

## 5. 查看与筛选消息

### 5.1 全部消息与单群消息

- 点击顶栏「全部」回到跨群视图，汇总所有已监控群的消息
- 点击某个群名进入该群的独立视图，只看这个群的消息
- 再次点击同一个群名，会退回「全部」视图

### 5.2 匹配过滤

每条消息右上角会显示是否「匹配开奖」：

- **默认显示匹配消息**：列表中只显示 `matched=1` 的消息（与当前开奖配置相关）
- **显示全部消息**：关闭顶部「仅匹配」开关，可查看所有原始消息，便于核对上下文

### 5.3 分页浏览

- 最新消息在底部，旧消息在顶部
- 滚动到顶部会自动加载上一页（每页 200 条）
- 若当前页已是最早记录，顶部会提示「没有更早的消息」

### 5.4 消息类型

支持以下类型的渲染与交互：

- **文本**：自动解析链接与表情
- **图片**：点击可放大预览；支持右键另存为
- **音频/视频**：内置播放器，可播放与下载
- **文件**：显示文件名与大小，点击可下载

失败解码的消息会保留原始字节，并在卡片右下角显示 `decode error`，方便排查。

## 6. 开奖配置

本应用支持对接第三方开奖 API，用于判断群消息是否包含当期开奖结果。

### 6.1 查看当前开奖

消息面板顶部显示「开奖信息条」：

- **本期期号**：最近一次从 API 拉到的期号
- **上期期号**：上一条历史期号（若存在）

### 6.2 修改开奖配置

1. 点击开奖信息条上的「编辑」按钮
2. 在弹出的编辑框填写完整的开奖 API 地址（例如 `https://go124.com/api/hash/get28HistoryList/10091`）
3. 点击「保存」，应用会自动拉取历史并更新关注期号列表
4. 保存后，正在监控的群内新消息会重新用新规则匹配

### 6.3 注意事项

- 默认配置的 URL 仅作为示例，实际使用时请替换为你关心的开奖源
- 期号列表从 API 返回的历史中自动提取；若返回为空或格式异常，匹配功能不会生效
- 修改配置后不会清空已有消息，只会影响新入库消息的匹配结果

## 7. 多账号管理

顶栏账号菜单提供以下操作：

- **切换账号**：免登切换到另一个已保存账号；原账号连接会自动断开
- **添加账号**：以空白表单新开登录流程，原有账号全部保留
- **退出登录**：断开连接并清除当前会话视图，Token 仍保存在本地；下次启动仍可恢复
- **移除账号**：永久删除该账号的 Token 与本地数据库，操作前会二次确认

### 切换账号的流程

1. 点击账号菜单 → 选择目标账号
2. 界面短暂显示「正在切换账号」
3. 新账号登录后自动加载群列表与消息；原账号的 TCP 连接已断开

## 8. 消息保留与清理

所有消息默认保留 **7 天**（`MESSAGE_RETENTION_DAYS = 7`），超过保留期的消息会被自动删除：

- **退出时清理**：关闭应用前会自动在后台清理过期消息
- **登录后清理**：成功登录后的第一时间也会触发一次清理

清理为异步后台任务，不会阻塞界面。清理完成前后消息列表长度会自然变化，这是预期行为。

如需调整保留时长，需要修改源码中的常量并重新构建应用。

## 9. 常见问题

### 9.1 收不到实时消息

- 确认顶栏状态为「已连接」
- 确认目标群处于「监控开启」状态
- 切换网络后可能需要手动「断开」再「连接」
- 检查是否正确勾选了当前群的监控开关

### 9.2 消息显示乱码或 `decode error`

- 部分特殊格式消息可能暂不被解析，属正常现象
- 可在消息卡片右下角看到错误原因
- 若连续大量出现，可能是版本或协议变更导致，可反馈给开发者

### 9.3 图片/文件打不开

- 附件会先下载到本地缓存再解密，首次打开需等待下载完成
- 请确认应用具有磁盘写入权限
- 部分文件类型受系统关联程序限制，可右键「另存为」后手动打开

### 9.4 登录成功后群列表为空

- 点击左侧「刷新」按钮重新同步
- 若长期为空，可能是账号未关注任何群，或远端同步接口异常

### 9.5 退出后重新打开丢失消息

- 应用使用本地 SQLite 持久化，正常情况不会丢失
- 若出现异常，可能是存储目录权限不足或磁盘空间耗尽
- 可查看应用日志（`im-app/src/main.rs` 输出）或重新安装

## 10. 隐私与安全

- 消息正文在传输过程中采用 AES-256-CBC 加密，密钥通过 X25519 密钥交换协商
- 登录 Token 与密钥对仅存储在本地 SQLite，不会上传到第三方
- 前端页面仅加载必要的验证码与媒体资源，其他外部域名均被 CSP 拦截
- 开奖 API 地址由用户自行配置，应用本身不附带任何默认可信列表
