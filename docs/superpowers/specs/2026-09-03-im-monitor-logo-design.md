# IM Monitor Logo 设计

## 1. 目标

为监控 55 App 群消息并向外广播的桌面小工具设计应用 Logo。

Logo 必须满足：

- 用户能一眼识别其与 55 App 的关联；
- 明确表达持续监听群消息的“雷达”概念；
- 在桌面、Dock、任务栏和安装包等小尺寸场景中保持清晰；
- 使用纯图形，不添加产品名称、`IM` 或中文文字。

## 2. 已选方向

采用 B1“柔和全屏雷达”。

保留 55 App 原 Logo 的核心视觉：

- 背景使用原色 `#178AFF`；
- 圆角比例沿用原始 `61 × 61` SVG 的 `rx="15"`；
- 两个数字直接复用原始矢量路径，不使用字体近似；
- 左侧“5”保持纯白；
- 右侧“5”保持纯白并使用 `0.4` 透明度；
- 数字的位置、大小和相互关系不做改绘。

原始参考：

`https://m1ee01u4.mocaijiaoyu.top/logo.svg`

## 3. 雷达图形

雷达位于双“5”下层，避免改变原标志轮廓。

使用原始 `61 × 61` 坐标系定义：

- 中心点：`(30.5, 30.5)`；
- 三层同心圆半径：`25`、`17`、`9`；
- 雷达线颜色：`#A7FFEA`；
- 三层线条透明度依次为 `0.55`、`0.45`、`0.40`；
- 扫描线从中心指向右上区域，颜色 `#8CFFE2`；
- 右上目标点使用 `#8CFFE2`；
- 扫描扇面使用 `#71F0D0`，透明度 `0.22`。

雷达只作为背景信息。视觉层级必须保持：

1. 双“5”；
2. 雷达扫描线和目标点；
3. 雷达同心圆与扫描扇面；
4. 蓝色背景。

## 4. SVG 结构

正式 SVG 使用 `viewBox="0 0 61 61"`，不依赖外部字体、图片或滤镜。

图层顺序：

1. 蓝色圆角矩形；
2. 半透明扫描扇面；
3. 三层同心圆；
4. 扫描线和目标点；
5. 55 App 原始双“5”路径。

所有颜色、透明度和几何参数直接写入 SVG，确保浏览器、Tauri 和系统图标转换工具输出一致。

## 6. 小尺寸策略

- `64px` 及以上：保留三层同心圆、扫描扇面、扫描线和目标点；
- `32px`：允许栅格化自然弱化最内层圆，但不使用另一套图形；
- `16px`：以双“5”识别度优先，雷达背景允许仅表现为浅色纹理；
- 不增加描边补偿或重新绘制数字，避免不同尺寸出现品牌形态不一致。

## 7. 验证

生成后检查：

1. SVG 可被浏览器和图像工具正常解析；
2. `16px`、`32px`、`64px`、`128px`、`256px` 和 `1024px` 预览无裁切；
3. 双“5”与原始 Logo 路径一致；
4. 小尺寸下首先识别到“55”，随后识别到雷达；
5. Tauri 图标生成命令成功；
6. 前端构建和 Tauri 配置检查通过；
7. Git diff 不覆盖当前工作区已有的无关修改。
